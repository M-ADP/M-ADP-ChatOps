# Dev-0.1.6 ChatOps Port Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the validated ChatOps accuracy, observability, and operator-facing API improvements from the `dev-0.1.3` working tree onto `dev-0.1.6` without regressing the newer session-message, runtime-metadata, and session-summary architecture.

**Architecture:** Reapply the portable parsing and name-resolution logic first, then adapt entity memory to `session_summary.recent_entities` instead of reintroducing a separate entity table. After the resolution layer is stable, add structured request lifecycle events and finally restore the operator-facing request browsing/search APIs so they coexist with the newer message-centric endpoints.

**Tech Stack:** Python, FastAPI, SQLAlchemy, Pydantic v2, LangGraph, pytest
